FrostHaven 是一个《星露谷物语》的末世极寒生存模组。当全球气候系统突然崩溃，星露谷的温度骤降至 -50°C，原本温馨的田园生活被严寒吞噬。你将在这个被冰雪封锁的世界中，不仅要为自己求生，更要团结社区、重建希望。

黑暗中有希望。生存是真实的，努力有回报，社区终将重建。

# 安装指南
## 前置要求
- SMAPI 4.0.0 或更高版本
- 星露谷物语 1.6 或更高版本
- Content Patcher（推荐，用于内容包扩展）

## 安装步骤
1. 确保已正确安装 SMAPI
2. 下载 FrostHaven 模组压缩包
3. 将解压后的 FrostHaven 文件夹放入游戏的 Mods 目录
4. 通过 SMAPI 启动游戏

## 兼容性说明
FrostHaven 是一个内容扩展模组，会显著改变游戏的世界观和玩法。建议在新存档中体验完整故事。与其他大型扩展模组（如 SVE）的兼容性尚在测试中。
